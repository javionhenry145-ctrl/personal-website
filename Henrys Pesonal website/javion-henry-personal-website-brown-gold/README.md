# Javion Henry's Personal Website

A responsive personal website built with HTML5 and CSS3.

## Features
- About Me, sports achievement, hobbies, photo gallery, contact details, and footer sections.
- Responsive layout for desktop, tablet, and mobile.
- External stylesheet and locally stored photos.
- Warm brown and gold color palette.

## Colour palette
- `#bb9457` — warm gold for links, buttons, and highlights.
- `#ffe6a7` — pale golden yellow for tinted sections and accents.
- `#432818` — deep brown for headings and main text.
- `#99582a` — darker brown for hover states.

## Folder structure
```text
javion-henry-personal-website-brown-gold/
├── index.html
├── README.md
├── css/
│   └── style.css
└── images/
    ├── javion-photo-1.jpg
    └── javion-photo-2.jpg
```

## Run locally
Keep the files and folders together, then open `index.html` in a web browser.
